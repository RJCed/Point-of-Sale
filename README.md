# Simple Point of Sale System

A simple **C-based Point of Sale (POS) program** for recording grocery items, calculating the total cost, and applying customer discounts.

## Features

* Add multiple grocery products
* Record product name, price, and quantity
* Calculate the total cost
* Apply customer discounts:

  * **PWD:** 5%
  * **Senior Citizen:** 20%
  * **Pregnant:** ₱30.00
  * **None:** No discount
* Includes basic input validation and error handling
* Uses a linked list to store product information

## How to Run

Compile the program using:

```bash
gcc pos.c -o pos
```

Then run:

```bash
./pos
```
